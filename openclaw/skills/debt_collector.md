# Debt Collector Skill — OpenClaw

## Триггер
Активируется при любом входящем сообщении от известного должника через WhatsApp / Telegram.

## Алгоритм обработки

### Шаг 1 — Определить намерение
Проанализируй текст сообщения:
- `promise`        — клиент обещает заплатить (указывает дату)
- `refusal`        — клиент отказывается платить
- `delay_request`  — клиент просит отсрочку
- `question`       — клиент задаёт вопрос (реквизиты, сумма и т.д.)
- `unclear`        — намерение неясно

### Шаг 2 — Действие по намерению

| intent          | Действие                                                    |
|-----------------|-------------------------------------------------------------|
| `promise`       | Подтвердить дату, вызвать `update_debt_status(promise)`     |
| `refusal`       | Зафиксировать, эскалировать менеджеру                       |
| `delay_request` | Уточнить новую дату, ответить с просьбой указать конкретно  |
| `question`      | Ответить: реквизиты / сумма / контакт менеджера             |
| `unclear`       | Задать уточняющий вопрос                                    |

### Шаг 3 — Формирование ответа
- Тон соответствует уровню клиента (1–5) из `collector_state.json`
- Язык: тот же что использовал клиент
- Длина ответа: 2–4 предложения
- Завершить конкретным вопросом если намерение неясно

## Инструменты
- `update_debt_status(client_name, intent, promise_date, promise_amount)` — обновить DB
- `get_client_level(client_name)` → int — получить текущий уровень давления
- `escalate_to_manager(client_name, message)` — уведомить ответственного менеджера
