## 7. WA Contacts — Root Cause Analysis

### Архитектура контактов

```
Коллектор при запуске вызывает:
  load_contacts_compat()  ← bot/crm_clients.py

  1. Загружает config/debtors_contacts.json (84 записи, все whatsapp="")
  2. Загружает config/clients.json (551 запись, 220 с WA)
  3. clients.json ПЕРЕКРЫВАЕТ debtors_contacts.json (CRM — приоритет)
  → Возвращает словарь с реальными телефонами из CRM
```

**CRM уже является основным источником контактов. Код работает правильно.**

### Почему WA-контакты частично пустые

**Причина:** 15 из 23 должников никогда не вводили телефон ни в CRM, ни в debtors_contacts.json.
Это **data gap**, не баг кода.

**Источник для добавления телефонов:**
- Менеджеры знают телефоны своих клиентов
- Телефоны можно взять из переписки, WhatsApp-истории, визиток
- CRM поддерживает добавление: `/phone ИмяКлиента 87XXXXXXXXX`

### Ответы на вопросы

**1. Почему бот не берёт WhatsApp из CRM автоматически?**
Берёт. `load_contacts_compat()` использует CRM как основной источник. Проблема — у большинства должников нет телефона вообще.

**2. Это архитектурное решение или legacy gap?**
Архитектурное решение (intentional): CRM — primary source, debtors_contacts.json — fallback. Реализовано корректно.

**3. Что нужно изменить, чтобы CRM был trusted source for WhatsApp?**
Ничего — он уже trusted source. Нужно только заполнить телефоны в CRM для 15 клиентов без номера.

**4. Что минимально нужно для первого test send в понедельник?**
Снять стоп-лист для ТОО ГудФуд или ИП Шахин — телефоны уже есть в CRM.
