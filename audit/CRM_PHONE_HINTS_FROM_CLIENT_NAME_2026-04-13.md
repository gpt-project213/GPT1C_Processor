# CRM phone hints from client names — 2026-04-13

Автор: Codex

## Цель

Использовать телефоны, которые уже указаны в названиях клиентов 1С, как подсказку менеджеру.

Важно: номер из названия не записывается автоматически. Менеджер должен подтвердить его кнопкой или ввести другой номер.

## Что изменено

- Добавлено извлечение казахстанских номеров из названия клиента.
- Номера нормализуются к формату `+7XXXXXXXXXX`.
- CRM-запрос телефона теперь может показать найденный номер как вариант.
- Для одного найденного номера доступны только две кнопки:
  - `Да, записать`
  - `Указать другой номер`
- Для нескольких найденных номеров доступна кнопка на каждый номер и `Указать другой номер`.
- Кнопок `Пропустить`, `Не знаю`, `Позже` на шаге телефона нет.
- При подтверждении найденного номера сохраняется `phone_source = client_name_confirmed`.
- При ручном вводе номера сохраняется `phone_source = manager_manual`.
- `contacts.xlsx` теперь содержит две дополнительные колонки:
  - `Телефон из названия`
  - `Источник телефона`

## Безопасность

- Автозаписи номера из названия нет.
- WhatsApp по найденному номеру не отправляется, пока менеджер не подтвердит номер.
- Если менеджер выбирает `Указать другой номер`, задача остаётся открытой до ввода валидного телефона.
- Если менеджер молчит, существующая pending-логика продолжает напоминать.
