# Кандидаты на WhatsApp-напоминание — для подтверждения менеджерами

Дата списка: 11.04.2026

Этот список нужен не для автоматической отправки. Сначала менеджер должен подтвердить: кому писать, каким тоном и есть ли правильный WhatsApp-номер.

Простое правило:

- если клиент в стоп-листе и долг висит — скорее всего, надо напоминать строго;
- если клиент платит, но долго закрывает долг — надо напоминать мягко и просить график;
- если клиент продолжает брать товар при старом долге — менеджер должен проверить ситуацию;
- если нет номера — сначала нужен WhatsApp-номер.
